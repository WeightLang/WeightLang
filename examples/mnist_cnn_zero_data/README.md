# 真正 CNN 的严格零数据初始化实验

本实验使用当前本地 WGT 0.3。目标是在真实卷积网络中直接初始化全部参数，
不读取训练/验证数据，不拟合真实或合成数字，不使用预训练权重、优化器或反向传播。

MNIST 官方测试集的本次固定方案结果：

| 初始化 | 正确 / 总数 | 准确率 |
| --- | --- | --- |
| WGT 自定义解析初始化 | 2,849 / 10,000 | **28.49%** |
| 同结构随机初始化，seed=42 | 784 / 10,000 | **7.84%** |

绝对差为 **20.65 个百分点**。随机对照只有一个预先固定的种子，不代表随机
初始化的平均表现；这也不是对模型训练后性能或收敛速度的验证。
自定义 CNN 效果明显不足，不能作为可靠识别器。

## 网络是真实 CNN

```text
[1,28,28]
  Conv2d(1,8,5,padding=2) -> ReLU -> MaxPool2d(2)
[8,14,14]
  Conv2d(8,8,3,padding=1) -> ReLU -> MaxPool2d(2)
[8,7,7]
  Flatten -> Linear(392,40) -> ReLU -> Linear(40,10)
[10]
```

共 **16,922 个参数**。卷积核在空间位置之间共享；推理包含真实的局部卷积、
非线性、池化和全连接运算，不是把整张数字图片存在线性层里计算最近模板。
参数都保留 `requires_grad=True`，但本次运行处于 inference mode，不构建训练图。
只验证了可训练参数的结构/标志，未测试后续训练效果。

## 权重如何生成

所有权重算法都在 [init.wgt](init.wgt)，没有 Python 初始化回调。

1. **第一卷积层：解析方向核。** 对水平、垂直和两种斜向，各生成两个尺度的
   高斯脊线滤波器。减去均值使其直流响应为零，再将正半部的总和归一化为 1。
   这些核只描述局部线条方向，不包含完整数字。
2. **第二卷积层：方向聚合。** 沿对应方向平滑前一层响应，并将同方向另一尺度
   的响应以 0.25 权重融合。两次 ReLU 和池化提供非线性与局部位置容忍。
3. **第一全连接层：区域证据。** 在池化特征图上，用归一化高斯区域权重提取
   上横、中横、下横、左右竖线、中竖和斜线等 10 种局部证据，
   每种使用 4 个小位置偏移，共 40 个神经元。
4. **分类层：显式人工先验。** 根据各数字通常包含/不包含的局部笔画，
   为证据分配正负系数；分别归一化正负证据，四个位置偏移取平均。
   全部偏置置零。

仅有方向滤波器并不能赋予输出编号 0..9 的语义，因此分类层仍需人工提供类别知识。
这里没有读取样本估计系数，没有闭式回归，也没有生成带标签的合成数字。
这种手工先验很粗糙，尤其难以覆盖弯曲、连笔和不同书写位置。

输入预处理仅为 `uint8 / 255`；没有额外裁剪、校正、数据增强、拟合归一化。
预测为网络最后 10 个分数的 argmax，没有外部规则分类器。

## 实验约束和验证

- 两个模型的结构、参数布局及测试输入完全相同，区别只有初始化。
- 在打开测试图片和标签前，保存算法源码、实验方案、两个完整模型与权重 SHA256。
- 每个模型完整评估 10,000 张一次，没有按结果修改设计或挑选种子。
- 禁止 `Tensor.backward`、`autograd.backward` 和 `autograd.grad` 入口；
  用 Python 审计钩子阻止读取常规 MNIST 训练归档及混合 `mnist.npz`。
- 已验证实际 `Conv2d/Linear` 类型、局部方向响应、参数有限性、
  WGT 前向与显式 PyTorch CNN 公式一致、CPU 保存重载逐位一致、
  测试前后全部权重完全不变且没有梯度。
- 前一次不同算法的实验已经使用过 MNIST 测试集，因此不能称本次为全新盲测。
  本次 CNN 没有基于测试结果做后续调整。

## 复现

仓库根目录执行；已有输出拒绝覆盖：

```bash
PYTHONPATH=src .venv/bin/weightc check examples/mnist_cnn_zero_data/model.wgt --shapes
PYTHONPATH=src .venv/bin/python examples/mnist_cnn_zero_data/evaluate.py \
  --output weights/mnist-cnn-zero-data-repeat
```

脚本只读取两个 MNIST 官方测试 gzip，默认在
`examples/mnist/.cache/weightlang/data/raw/`，可用 `--data-dir` 指定其他目录。
文件名为 `t10k-images-idx3-ubyte.gz` 和 `t10k-labels-idx1-ubyte.gz`，读取时核对
MD5、IDX 头、形状和标签范围。缺少文件会退出，不调用训练数据准备脚本。
使用 `--device cpu` 可切换到 CPU。

本次环境：Torch 2.14.1+cu130、Python 3.14.9、RTX 4060 Laptop GPU。
保留结果在 `weights/mnist-cnn-zero-data-v1/`：

- `custom/mnist_cnn_zero_data/` 与 `random/mnist_cnn_zero_data/`：两个完整模型。
- `sources/`：准确的源文件和随机对照源文件快照。
- `plan.json`、`frozen_weights.json`：评估前冻结的方案及权重摘要。
- `report.json`、`predictions.csv`：指标、混淆矩阵、验证记录和全部逐样本预测。

本轮只新增独立实验，没有改语言/运行时，没有提交、推送或公开发布。
