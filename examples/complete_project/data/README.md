# 合成数据

本示例原创数据随仓库按 MIT 许可分发。每行按 `y = 2*a - b + 0.5` 计算，
前三列依次是两个输入和一个目标，首行是表头。

训练集取 `{-1, 0, 1}²` 中除 `(0, 0)` 外的 8 个点。
验证集为 `(0, 0)`、`(0.5, 0.5)`、`(-0.5, 0.5)`，与训练集没有重复。
JSON 行为测试还检查 `(0.25, -0.75)`。

模型声明中的 SHA-256 覆盖 CSV 的原始字节，包括表头与换行；`skip=1` 跳过表头。
修改数据后，在工程根目录用 `sha256sum data/*.csv` 获取新哈希并更新模型。
验证样本不参与优化，但这个极小的合成任务不能代表真实世界性能。
