# 用 WGT 自定义初始化实现零训练数字识别

本实验使用当前本地 WGT 0.3 实现，不修改语言或运行时。**MNIST 官方测试集
10,000 张，正确 5,332 张，准确率 53.32%。** 这是一次固定设计后的完整测试，
没有根据测试结果修改算法。不是高准确率识别器。

## 零训练的含义

- 不读取 MNIST 训练集或验证集，不使用预训练模型或从样本估计参数。
- 没有损失函数、优化器、反向传播或参数更新；运行时禁止 autograd 的 backward/grad 入口。
- 人工编写数字笔画是先验知识，因此不等于“没有任何关于数字的知识”。
- 初始化算法和模型前向均由 WGT 定义。Python 只负责构建、数据预处理、评估和报告。

## 算法

`init.wgt` 用折线表示 0–9 的笔画。对每个像素，计算到最近笔画线段的距离 d，
再用 `exp(-d² / (2σ²))` 渲染灰度模板。模板包含 3 种宽度、3 种倾斜、
2 种笔画粗细、3×3 种平移及 2 个写法槽位，共每类 324 个模板。
部分数字的两个写法相同，故不是 324 个互异模板。

每个模板展平并归一化为单位向量，直接放入线性层的一行权重，无偏置。
模型有 2,540,160 个参数，保存的权重约 9.7 MiB。
输入图像同样展平并作逐图 L2 归一化。完整 WGT 前向为：

```text
784 个像素 → linear(3240, bias=0) → reshape(10,324) → 每类取 max → 10 类相似度
```

数学上：`score[c] = max_j <x / ||x||, template[c,j] / ||template[c,j]||>`。
Python 最后取最高分类分数的 argmax。分数是余弦相似度，不是校准后的概率。
它本质上是将人工模板匹配编码成模型权重，不是通过初始化“凭空学会”数字。

## 本次结果

| 数字 | 正确 / 样本 | 召回率 |
| --- | --- | --- |
| 0 | 598 / 980 | 61.02% |
| 1 | 812 / 1135 | 71.54% |
| 2 | 387 / 1032 | 37.50% |
| 3 | 705 / 1010 | 69.80% |
| 4 | 724 / 982 | 73.73% |
| 5 | 251 / 892 | 28.14% |
| 6 | 712 / 958 | 74.32% |
| 7 | 106 / 1028 | 10.31% |
| 8 | 589 / 974 | 60.47% |
| 9 | 448 / 1009 | 44.40% |

常见错误：9→4 为 471 张，7→2 为 364 张，7→9 为 346 张。
固定几何模板不能充分覆盖实际书写差异，像素相似度也不能可靠区分相近笔画结构。
这些是本次结果的局限；没有为改善该测试分数重新选择模板。

本次使用 RTX 4060 Laptop GPU、Torch 2.14.1+cu130。
构建和保存重载验证约 16.60 秒，测试推理约 59.41 秒；只是本次执行计时，
包含批次准备/传输等开销，不是独占机器条件下的性能基准。

## 复现与验证

在仓库根目录执行，已有输出会拒绝覆盖：

```bash
PYTHONPATH=src .venv/bin/weightc check examples/mnist_zero_train/model.wgt --shapes
PYTHONPATH=src .venv/bin/python examples/mnist_zero_train/evaluate.py \
  --output weights/mnist-zero-train-geometric-repeat
```

默认复用 `examples/mnist/.cache/weightlang/data/raw/` 中的两个官方测试 gzip，
缺失时只下载测试集，逐一核对 MD5，报告保留 SHA256。
可用 `--data-dir` 指定缓存、`--device cpu` 改为 CPU。
模型在读取任何测试图片和标签之前构建并保存。已验证模板单位范数、
WGT 前向与显式公式一致、保存重载输出逐位一致、评估前后权重完全不变。
未运行训练，也没有运行远程 CI。

本次保留目录：`weights/mnist-zero-train-geometric-v1/`，包含：

- `mnist_zero_train/`：完整模型（manifest、source、safetensors）。
- `sources/`：本次初始化算法、模型定义和运行脚本的准确快照。
- `report.json`：指标、混淆矩阵、环境、源文件和数据集摘要。
- `predictions.csv`：10,000 条按原始顺序排列的标签和预测。

加载完整制品时不再执行初始化，可能显示“未训练或直接编辑权重”的提示，这是准确的状态。
源码快照用于重建，完整制品用于直接推理；不要将它标记为经过训练的权重。
