# 用 WeightLang 训练一个微型中文语言模型

这是一个**已经在本地实际训练过的实验原型**：76,207 个参数，两层因果
Transformer、四个注意力头、64 维隐藏状态、48 字符上下文。每次预测下一个
字符，再把预测结果接回输入，逐字生成一句话。不是预训练模型，也不是聊天助手。

网络全部定义在 [model.wgt](model.wgt)，使用当前源码实现的 `wgt 0.3` 和
`std/transformer`。Python 只负责准备数据、调用 WeightLang 编译/加载接口、
优化权重和采样，没有重新实现一套网络。这里验证的是当前本地源码，未发布。

## 直接运行

在仓库根目录，使用已有的 `.venv`（需要 PyTorch、safetensors）：

```sh
# 检查形状。这一步只检查结构，不训练。
PYTHONPATH=src .venv/bin/weightc check examples/tiny_lm/model.wgt --shapes

# 使用本次已经训练并保存的模型。
PYTHONPATH=src .venv/bin/python examples/tiny_lm/generate.py --prompt '早上，小明'

# 从零再训练；必须选择尚不存在的实验目录。
PYTHONPATH=src .venv/bin/python examples/tiny_lm/train.py --output weights/tiny_lm_second
PYTHONPATH=src .venv/bin/python examples/tiny_lm/generate.py \
  --model weights/tiny_lm_second/trained --prompt '晚上，小红来到' --seed 7
```

`train.py` 默认运行 600 步、batch 32、AdamW 学习率 0.002，固定种子 42，
使用 CPU 和四个线程。`--steps` 可调整步数，默认输出为
`weights/tiny_lm_demo/`。已有目录直接拒绝覆盖，包括符号链接。

`generate.py` 支持 `--prompt`、`--model`、`--seed`、`--temperature`（默认 0.7）
和 `--max-new`（默认最多 60 个新字符）；生成 EOS 时提前停止。
温度越低，越倾向选择高分字符。空提示会从 BOS 开始生成。
超出 48 字符时仅使用最近 48 字符，并重新从位置零编码；训练只包含短句，
没有验证长文本质量。字表外输入会明确报错，不会悄悄替换字符。

## 数据和学习过程

[data.py](data.py) 生成本示例原创的 864 条合成句子，采用以下组合：

```text
时间，小某来到地点。小某喜欢活动，今天很开心。
```

8 个人名 × 6 个地点 × 6 种活动 × 3 个时间。固定随机打乱后，777 条用于
训练，87 条用于验证，两边没有完整重复句子，但共享同一语法和词汇。
47 个 token 包含 44 个字符与 PAD/BOS/EOS；字符表由预先定义的合成语法确定。
这只检验同一模板内的组合学习，不能证明理解中文或具备开放领域能力。
修改语料字符后，要同步调整 `model.wgt` 的 `VOCAB`。

输入是 `BOS + 句子`，目标向右错开一位，末尾预测 EOS。
不足长度在右侧补 PAD，交叉熵忽略 PAD 目标。因果注意力屏蔽未来字符；
生成时也右侧补齐固定形状，但只读取当前最后一个有效位置的预测。
两层 decoder 各有独立权重，每层在各时间位置之间共享权重。

每 100 步测量验证集，保留验证损失最低的权重。没有独立测试集，验证集用于
选择模型，所以这里的指标不能当作独立测试成绩。字符准确率是在给定真实前文
时预测下一个字符的准确率，不是整句生成成功率。

## 本次实际结果

CPU 训练循环和评估约 6.7 秒（不含进程启动、编译和保存，其他机器可能不同）。

| 验证指标 | 随机初始化 | 600 步后 |
| --- | ---: | ---: |
| 交叉熵，越低越好 | 4.1172 | 0.2853 |
| 困惑度，越低越好 | 61.3849 | 1.3302 |
| 下一个 token 准确率 | 0.24% | 86.54% |

困惑度是交叉熵的指数；这里语法极简单，所以数值很低，不适合与真实语料上的
语言模型比较。随机选择的人名、地点、活动也使得某些位置没有唯一正确答案。

从**保存后重新加载的权重**采样，温度 0.7、种子 42：

```text
提示：早上，小明
生成：早上，小明来到河边。小明喜欢写诗，今天很开心。

提示：晚上，小红来到
生成：晚上，小红来到学校。小红喜欢散步，今天很开心。

提示：中午，小林
生成：中午，小林来到河边。小林喜欢写诗，今天很开心。
```

这些输出只是样本，不保证新颖性，也不是独立泛化证据。

## 保留文件与验证

默认实验完整保存在仓库根目录的 `weights/tiny_lm_demo/`：

- `baseline/tiny_char_lm/`：完整随机初始化制品及字表。
- `trained/`：完整已训练制品，包含 `manifest.json`、`source.wgt`、
  `weights.safetensors`、`tokenizer.json`；请一起保留。
- `dataset.json`：本次实际训练/验证划分。
- `report.json`：训练曲线、指标、样本、代码与数据 SHA-256、验证结果。

训练脚本实际检查：整句划分无交集；修改未来输入不会改变前缀输出；
保存重载后的 logits 与内存模型完全一致。训练中检查有限损失并裁剪梯度。
这套演示不修改语言实现，不需要重新编译 Rust，也不下载外部数据或模型。
模型输出默认被仓库忽略，源码示例可以版本管理。
